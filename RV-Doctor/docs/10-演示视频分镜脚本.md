## 3. 录制与提交清单

- [ ] **旁白**：按上表录制，语速约 240 字/分钟；术语念法：ASR 逐字母念，llama 念"拉玛"，`-ub` 念"u-b 参数"；
- [ ] **实拍**：机位 A/B 各拍一遍，注意屏幕反光与手指遮挡；
- [ ] **录屏**：终端页用浏览器全屏抓，缩放 100%，字体调大；证据 JSON 用编辑器放大字号后再录；
- [ ] **剪辑**：等待时间**不要压缩**（真实感是加分项），但可以在等待时叠字幕说明在做什么；
- [ ] **字幕**：所有数字配字幕，且与证据文件逐字一致；
- [ ] **片头片尾**：片头 3 秒项目名 + 一句话；片尾仓库地址 `https://github.com/HaoTianNiuBi/RISC-Git`；
- [ ] **审阅**：拿 [07-演示方案 §6](07-演示方案.md) 的问答口径过一遍，确认没有和文档冲突的表述；
- [ ] **格式**：导出 MP4（H.264 + AAC），单文件控制在 500 MB 以内（官方上传上限）。

## 4. 现场演示应急（总决赛用）

按顺序降级：

1. 千问冷启动太慢 → 先跑一次预热，或切到文本通路；
2. 麦克风失灵 → 用文本输入演示同一意图链路，解说里说明这是备用通路；
3. 板子起不来 → 播预录视频 + 展示证据 JSON；
4. 评委要求现场复现 → `validate.py --mode text_intent`，约 10 分钟，不依赖麦克风。
