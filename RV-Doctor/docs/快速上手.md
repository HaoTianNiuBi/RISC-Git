# 快速上手

RV-Doctor 在本机完成单文件 C 程序的 RISC-V 编译、QEMU 指令统计、规则诊断和可选 AI 优化验证。项目概览与完整导航见 [README](../README.md)，日常操作见 [操作手册](操作手册.txt)。

## 环境与安装

- Windows 10/11，Python **3.11+**（配置读取依赖 `tomllib`）。
- 将项目放在纯英文、无空格路径，例如 `D:\RISC-V-first`，以满足本地工具链的路径要求。
- 现有 `.venv/` 与 `tools/` 可直接继续使用；首次安装需要足够空间保存 Python 环境和解压后的 GCC/QEMU。

在项目中双击 `scripts/install.bat`。脚本会切回项目根目录，创建 `.venv`、安装 `requirements.txt` 中的依赖，并检查工具链。

本地离线工具链包已归入 `dist/offline/tools.zip`；脚本优先解压该文件，缺少时尝试在线下载。离线包被 Git 忽略，克隆仓库不会自动获得它；手动配置方式见 [环境搭建指南](04-环境搭建指南.md)。

默认工具布局：

```text
tools/gcc/bin/riscv-none-elf-gcc.exe
tools/gcc/bin/riscv-none-elf-objdump.exe
tools/qemu/qemu-system-riscv32.exe
tools/qemu/qemu-system-riscv64.exe
```

## 启动、体检与优化

1. 双击根目录 `启动体检台.bat`，打开 [本地体检台](http://localhost:8501)。
2. 选择架构、优化等级，粘贴 C 源码或上传单个 `.c` 文件，点击「一键体检」。
3. 查看指令统计、规则诊断和任务目录；需要 AI 候选时，填写 DeepSeek 配置并继续优化验证。Key 只保存在当前会话内存中。
4. 关闭启动窗口或双击根目录 `停止体检台.bat` 停止服务。

未填写 API Key 时，基础体检与规则诊断仍可使用。AI 候选只有通过编译、输出一致性和指标验证后才接受。当前入口针对单文件 C，尚未提供 C++ 工程或网页上传 ELF。

## 自检与排查

在项目根目录执行：

```powershell
.\scripts\run_all_checks.bat
.\.venv\Scripts\python.exe -X utf8 scripts/e2e_check.py
```

| 现象 | 处理 |
|---|---|
| 提示缺少 `.venv` | 先运行 `scripts/install.bat` 或按环境指南手动安装 |
| 提示找不到 GCC/QEMU | 检查 `tools/` 布局与根目录 `config.toml` |
| 编译、链接或 trace 路径报错 | 确认整个项目路径为纯英文、无空格 |
| 页面打不开 | 检查启动窗口的错误，确认本地 8501 端口与服务状态 |
| 大程序体检慢 | QEMU 逐条记录指令；先使用内置小型基准，并查看任务日志 |

## 文件放在哪里

目录用途见 [目录说明](目录说明.md)，脚本用途见 [脚本导航](../scripts/README.md)。PPT/PDF 在 `docs/presentation/`，早期运行时实验在 `docs/archive/runtime-experiments/`。

每次体检的源码、ELF、stdout、trace、指标、候选验证与报告保存在 `workdir/<任务号>/`。这些是实测结果的证据，应按任务用途保留。固定测试 trace、二进制样例、冻结快照和 `reports/data/` 也参与验证与溯源。

能耗分是指令类别加权得到的相对估算；QEMU 统计不等同于真实硬件时序或功耗测量。
