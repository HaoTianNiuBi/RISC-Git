# 目录说明

项目按「运行入口 → 业务模块 → 验证与维护 → 文档与本地产物」组织。根目录保留日常启动入口和现有 Python 模块路径，编译器、QEMU 与任务目录的定位方式保持一致。

| 位置 | 用途 |
|---|---|
| `app.py`、`pipeline.py` | 网页入口与体检、优化流程编排 |
| `compiler/` | GCC、objdump 封装与正式裸机运行时 |
| `profiler/` | QEMU 执行、trace 解析、性能指标与能耗估算 |
| `optimizer/` | 规则诊断、LLM 建议与候选验证 |
| `reports/report.py` | Markdown 对比报告生成 |
| `reports/data/` | 基准与演示实测数据，供技术文档和 PPT 引用 |
| `benchmarks/` | 10 个 C 基准、期望输出、冻结快照与优化候选 |
| `tests/fixtures/` | 固定测试镜像、trace 和 `environment/hello.c` 环境样例 |
| `scripts/` | 安装、自检、巡检、演示与维护脚本，详见其 README |
| `docs/01-*`～`11-*` | 需求、架构、环境、测试与参赛文档 |
| `docs/操作手册.txt`、`docs/快速上手.md` | 日常操作与首次安装说明 |
| `docs/presentation/` | PPTX、PDF 与生成脚本 |
| `docs/archive/runtime-experiments/` | 早期运行时及半主机实验，供复查，不参与正式编译 |
| `assets/` | 正式图标资源 |
| `workdir/` | 本地任务产物和原始证据，不入库 |
| `dist/offline/tools.zip` | 保留的离线安装包，不入库 |
| `tools/`、`.venv/` | 实际使用的工具链和 Python 环境，不入库 |
| `.streamlit/` | 界面主题配置 |

## 后续放置约定

新增维护脚本放 `scripts/`，文档放 `docs/`，演示材料放 `docs/presentation/`；临时编译、日志和预览放 `workdir/`，本地分发产物放 `dist/`。无需在项目内再复制一套业务源码。

`tests/fixtures/*.log`、`*.bin`、`benchmarks/expected/*.out`、冻结快照和 `reports/data/` 都有验证或溯源用途。`workdir/` 的历史任务含原始 trace、源码和失败现场，应按任务用途管理，避免仅凭扩展名或文件大小批量删除。

离线工具链包约 542 MiB，是独立的裁剪分发资源；当前 `tools/` 是已安装版本。两者都保留，虚拟环境、Git 历史与本地编辑器状态也保留。
