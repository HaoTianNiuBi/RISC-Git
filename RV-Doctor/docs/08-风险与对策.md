## 5. 合规与伦理

| 事项 | 处理 |
|---|---|
| 个人语音数据 | 录音不入库，只入库信号统计与评分 JSON；已删除的录音历史随仓库重建彻底清除 |
| 用户代码上传第三方 LLM 的隐私 | 主机侧界面明示「源码将发送至所配置服务商」；提供「仅规则引擎（不出网）」；凭据只存会话内存 |
| 第三方许可 | GCC/QEMU 以独立进程调用，不链接；对官方 SDK 与模型只按官方渠道下载，不转售、不再分发权重 |
| 数据真实性 | 任何估算显式标注；未做的测量不写；未达标项（4 s、现场 CER）照实写 |
| AI 辅助开发 | 材料中如实说明开发方式；核心实现（验证闭环、trace 统计、端侧链路）为自研 |
