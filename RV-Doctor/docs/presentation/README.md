## 文件

- `RV-Doctor成果提交.pptx`：9 月版可编辑演示文稿（高校赛道标注）。
- `RV-Doctor成果提交.pdf`：对应导出预览。
- `build_ppt.js`：原始生成脚本，数据口径来自 `reports/data/`；脚本内的赛道文案同样是 9 月口径。

仅查看材料无需安装 Node.js 依赖。如需重新生成，在本目录安装 `pptxgenjs` 后运行：

```powershell
npm install --no-save --package-lock=false pptxgenjs
node build_ppt.js
```

PPTX 输出到本目录；PDF 需要另行导出。
